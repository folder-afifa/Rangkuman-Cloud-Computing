Pengertian Cloud Computing

Cloud computing adalah model layanan komputasi yang memungkinkan pengguna mengakses sumber daya seperti server, penyimpanan, jaringan, dan aplikasi melalui internet.

Apa itu komputasi awan?

Dalam materi, cloud computing dijelaskan sebagai perkembangan komputasi terdistribusi yang memindahkan berbagai layanan ke internet sehingga pengguna tidak lagi bergantung penuh pada perangkat lokal.

Kenapa penting?

Cloud memudahkan individu maupun organisasi untuk menggunakan layanan komputasi secara lebih fleksibel. Pengguna bisa mengakses layanan dari berbagai tempat selama tersedia koneksi jaringan.

5 Karakteristik Utama

Lima karakteristik ini membuat sebuah layanan layak disebut cloud computing.

1

Resource Pooling

Sumber daya komputasi dikumpulkan oleh penyedia layanan untuk melayani banyak pengguna dengan model multi-tenant.

2

Broad Network Access

Layanan bisa diakses lewat jaringan dari banyak perangkat seperti laptop, tablet, dan smartphone.

3

Measured Service

Pemakaian layanan dapat dipantau dan diukur secara otomatis, misalnya bandwidth, storage, dan jumlah pengguna aktif.

4

Rapid Elasticity

Kapasitas layanan bisa dinaikkan atau diturunkan dengan cepat sesuai kebutuhan pengguna.

5

Self Service

Pengguna dapat melakukan konfigurasi layanan sendiri tanpa harus menunggu bantuan manual dari penyedia.

Inti utamanya

Cloud menawarkan layanan yang cepat, fleksibel, terukur, dan mudah diakses, sehingga mendukung efisiensi operasional.

Model Layanan Cloud

Terdapat tiga model layanan utama yang umum digunakan dalam cloud computing.

SaaS

Software as a Service

Pengguna langsung memakai aplikasi yang sudah disediakan provider. Contohnya email, dokumen online, dan aplikasi bisnis berbasis web.

  • Tidak perlu instalasi rumit
  • Mudah dipakai oleh pengguna akhir
  • Pembayaran biasanya berbasis langganan
PaaS

Platform as a Service

Pengguna menyewa platform untuk menjalankan aplikasi tanpa perlu mengurus infrastruktur secara detail. Cocok untuk pengembang aplikasi.

  • Fokus ke pengembangan aplikasi
  • Tidak perlu pusing mengelola server dasar
  • Contoh modern: layanan deploy web seperti Render, Railway, atau Vercel
IaaS

Infrastructure as a Service

Pengguna menyewa infrastruktur IT seperti CPU, storage, memory, dan jaringan. Kontrol lebih besar, tetapi pengelolaannya juga lebih banyak.

  • Lebih fleksibel untuk konfigurasi
  • Cocok untuk kebutuhan infrastruktur khusus
  • Skala resource bisa diubah sesuai kebutuhan

Deployment Model

Selain model layanan, cloud computing juga dibagi berdasarkan cara penerapannya.

Public Cloud

Layanan disediakan untuk masyarakat umum. Mudah diakses dan tidak membutuhkan investasi infrastruktur sendiri.

Private Cloud

Layanan cloud dibangun untuk kebutuhan internal organisasi. Kontrol lebih besar, tetapi biaya dan pengelolaan juga lebih tinggi.

Hybrid Cloud

Gabungan public cloud dan private cloud agar organisasi bisa menyesuaikan kebutuhan fleksibilitas dan keamanan.

Community Cloud

Dibangun untuk komunitas atau organisasi dengan kepentingan yang sama, misalnya terkait aturan, compliance, atau keamanan.

Manfaat dan Tantangan

Cloud computing memberi banyak keuntungan, tetapi tetap memiliki beberapa tantangan yang perlu diperhatikan.

Manfaat

  • Skalabilitas dan fleksibilitas tinggi
  • Efisiensi biaya dengan sistem pay-as-you-go
  • Akses dari mana saja melalui internet
  • Mendukung kolaborasi dan mobilitas kerja
  • Keamanan serta backup biasanya sudah disediakan provider

Tantangan

  • Bergantung pada koneksi internet yang stabil
  • Ada risiko keamanan dan privasi data
  • Kontrol terhadap infrastruktur lebih terbatas dibanding sistem lokal
  • Integrasi dengan aplikasi lama bisa menjadi tantangan
Cloud computing bukan hanya soal memindahkan data ke internet, tetapi tentang memanfaatkan layanan komputasi secara efisien, fleksibel, dan sesuai kebutuhan pengguna.

Tren Singkat Cloud Computing

Materi juga menyoroti beberapa perkembangan terbaru dalam penggunaan cloud.

Hybrid & Multi-Cloud

Organisasi mulai memakai lebih dari satu layanan cloud untuk fleksibilitas dan mitigasi risiko.

AI & Machine Learning

Cloud semakin mendukung pemrosesan AI dan machine learning tanpa harus membangun infrastruktur sendiri dari nol.

Cloud Native

Penggunaan container dan aplikasi cloud-native mempermudah deployment serta scaling aplikasi modern.

Pengantar FinOps

FinOps atau Financial Operations adalah praktik untuk mengelola biaya cloud dengan melibatkan tim teknologi, keuangan, dan bisnis.

Evolusi Biaya Komputasi

Pada model tradisional, perusahaan biasanya mengeluarkan biaya besar di awal untuk membeli perangkat keras fisik atau disebut CapEx. Pada model cloud, biaya berubah menjadi OpEx karena pembayaran dilakukan berdasarkan pemakaian atau pay-as-you-go.

Definisi FinOps

FinOps bukan hanya tentang memotong biaya, tetapi tentang memaksimalkan nilai bisnis dari setiap biaya yang dikeluarkan untuk cloud. Praktik ini menyatukan tim engineering, finance, product owner, dan executive agar penggunaan cloud lebih terkontrol.

Masalah yang sering muncul pada cloud adalah pemborosan biaya, misalnya resource yang idle, terlalu besar, atau tidak lagi digunakan tetapi masih aktif dan tetap menimbulkan biaya.

3 Fase Framework FinOps

Framework FinOps terdiri dari tiga fase utama, yaitu Inform, Optimize, dan Operate.

Inform

Memberi Visibilitas Biaya

Fase ini berfokus pada tagging, alokasi biaya, dan pelaporan yang akurat. Tujuannya agar organisasi tahu resource mana yang digunakan, siapa pemiliknya, dan berapa biaya yang dihasilkan.

Optimize

Mengoptimalkan Pengeluaran

Fase ini mencari peluang penghematan, seperti right-sizing, memakai reserved instances, spot instances, dan menghentikan resource yang tidak digunakan.

Operate

Menjadikan Efisiensi Kebiasaan

Fase ini mengintegrasikan efisiensi biaya ke operasional harian, termasuk penggunaan kebijakan, metrik performa, dan otomatisasi agar pengelolaan cloud lebih disiplin.

Pemangku Kepentingan dalam FinOps

FinOps membutuhkan kerja sama beberapa peran agar keputusan cloud tidak hanya teknis, tetapi juga sesuai anggaran dan tujuan bisnis.

Engineering

Membangun dan mengelola infrastruktur cloud. Fokus FinOps-nya adalah efisiensi penggunaan resource dan right-sizing.

Finance

Mengelola anggaran dan pelaporan. Fokusnya adalah prediksi biaya, kontrol pengeluaran, dan alokasi anggaran.

Product Owner

Menghubungkan biaya cloud dengan fitur dan nilai produk. Fokusnya adalah analisis biaya per fitur atau layanan.

Executive

Mengambil keputusan strategis organisasi. Fokusnya adalah ROI, nilai bisnis, dan pertumbuhan perusahaan.

Operasi Harian dan Pengukuran Nilai

FinOps diterapkan melalui kontrol biaya harian dan pengukuran biaya berdasarkan hasil bisnis.

Day-to-Day Operations

  • Automated governance: resource yang tidak dipakai dapat dihentikan otomatis di luar jam kerja.
  • KPI & metrics: efisiensi biaya dijadikan ukuran performa tim engineering.
  • Policy enforcement: dibuat aturan siapa saja yang boleh membuat server atau database berbiaya tinggi.

Unit Economics

FinOps tidak hanya bertanya “berapa total biayanya?”, tetapi juga “berapa biaya untuk satu transaksi bisnis?”. Contohnya adalah menghitung cost per transaction agar biaya cloud bisa dibandingkan dengan nilai yang dihasilkan.

Maturity Model FinOps

Tingkat kematangan FinOps menunjukkan sejauh mana organisasi mampu mengelola biaya cloud secara konsisten.

Crawl

Tahap Awal

Organisasi mulai membuat visibilitas dasar dan tagging, tetapi banyak proses masih manual.

Walk

Tahap Berkembang

Kebijakan optimasi mulai dijalankan secara rutin dan kolaborasi antar tim mulai terbentuk.

Run

Tahap Matang

Otomasi sudah berjalan penuh dan biaya cloud dipahami sebagai nilai strategis bisnis secara real-time.

Kesimpulan

Cloud computing menjadi fondasi penting dalam dunia teknologi modern karena mampu menyediakan layanan komputasi yang fleksibel, efisien, dan mudah diakses.

Dari materi ini dapat dipahami bahwa cloud computing memiliki karakteristik khas, model layanan yang berbeda, deployment model yang bisa disesuaikan dengan kebutuhan, serta tantangan biaya yang perlu dikelola melalui FinOps. Dengan memahami cloud computing dan FinOps, pengguna tidak hanya bisa melakukan deployment website ke platform cloud, tetapi juga memahami cara menggunakan resource cloud secara efisien, terukur, dan bernilai bagi bisnis.
